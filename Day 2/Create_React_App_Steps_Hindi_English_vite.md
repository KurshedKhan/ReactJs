
# ⚡ How to Create a React App using Vite (Vite से React ऐप कैसे बनाएं)

Vite एक तेज़ और मॉडर्न टूल है React ऐप बनाने के लिए। नीचे दिए गए स्टेप्स को फॉलो करें:

---

## ✅ Step 1: Install Node.js (Node.js इंस्टॉल करें)
आपके सिस्टम में Node.js होना ज़रूरी है।  
डाउनलोड करें: [https://nodejs.org](https://nodejs.org)

Node.js और npm चेक करने के लिए:
```bash
node -v
npm -v
```

---

## ✅ Step 2: Create React App using Vite (Vite से React ऐप बनाएं)
```bash
npm create vite@latest my-app -- --template react
```
यह `my-app` नाम का एक नया React प्रोजेक्ट बनाएगा।

---

## ✅ Step 3: Go to Project Folder (प्रोजेक्ट फोल्डर में जाएं)
```bash
cd my-app
```

---

## ✅ Step 4: Install Dependencies (पैकेज इंस्टॉल करें)
```bash
npm install
```

---

## ✅ Step 5: Start the Development Server (डिवेलपमेंट सर्वर शुरू करें)
```bash
npm run dev
```
अब ऐप `http://localhost:5173` पर चलेगा।

---

## ✅ Folder Structure (फोल्डर संरचना)
```
my-app/
├── node_modules/
├── public/
├── src/
│   ├── App.jsx
│   ├── main.jsx
├── index.html
├── package.json
└── vite.config.js
```

---

## ✅ Step 6: Edit App.jsx to Start Coding (App.jsx को एडिट करें)
Open `src/App.jsx` और कोडिंग शुरू करें!

---

## 📌 Conclusion (निष्कर्ष)
- Vite से React ऐप बनाना तेज़, आसान और मॉडर्न तरीका है।
- यह डेवलपमेंट के लिए हाई स्पीड और बेहतर एक्सपीरियंस देता है।

**Happy Coding with Vite! ⚡😄**
