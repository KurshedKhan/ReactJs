
# 🚀 How to Create a React App (React ऐप कैसे बनाएं)

Follow these simple steps to create a new React app using **Create React App**.

---

## ✅ Step 1: Install Node.js (पहले Node.js इंस्टॉल करें)
You must have **Node.js** installed.  
Node.js इंस्टॉल करने के लिए [https://nodejs.org](https://nodejs.org) पर जाएं और LTS वर्जन डाउनलोड करें।

To check if Node.js is installed:
```bash
node -v
npm -v
```

---

## ✅ Step 2: Install Create React App Globally (अगर ज़रूरत हो)
You can install Create React App globally (optional):
```bash
npm install -g create-react-app
```

---

## ✅ Step 3: Create a New React App (नया ऐप बनाएं)
Use the following command in terminal:
```bash
npx create-react-app my-app
```
यह `my-app` नाम का एक नया React प्रोजेक्ट बनाएगा।

---

## ✅ Step 4: Go to Project Folder (प्रोजेक्ट फोल्डर में जाएं)
```bash
cd my-app
```

---

## ✅ Step 5: Start the Development Server (डिवेलपमेंट सर्वर शुरू करें)
```bash
npm start
```
यह ऐप को ब्राउज़र में `http://localhost:3000` पर चलाएगा।

---

## ✅ Folder Structure (फोल्डर संरचना)
```
my-app/
├── node_modules/
├── public/
├── src/
│   ├── App.js
│   └── index.js
├── package.json
└── README.md
```

---

## ✅ Step 6: Edit App.js to Start Coding (App.js को एडिट करें)
Open `src/App.js` and start editing to build your UI!

---

## 📌 Conclusion (निष्कर्ष)
- React ऐप बनाना आसान है `create-react-app` की मदद से।
- बस कुछ कमांड्स चलाएं और आपका React ऐप तैयार है।

**Happy Coding! 😄👨‍💻**
