## 🧠 What is a Store in Redux?

The **Redux store** is a **central place** where your entire application's **state** lives.

---

## 🔑 Store Responsibilities

1. **Holds the state** of the application.
2. **Allows access to state** via `getState()`.
3. **Dispatches actions** via `dispatch(action)`.
4. **Registers listeners** via `subscribe(listener)`.
5. Handles **state updates** using reducers.

---

## 🛠 How to Create a Store (Classic Redux)

```js
import { createStore } from 'redux';
import rootReducer from './reducers';

const store = createStore(rootReducer);
```

> ⚠️ **Classic Redux** requires boilerplate and middleware setup manually.

---

## ✅ Recommended: Using `configureStore()` (Redux Toolkit)

Redux Toolkit simplifies store setup.

### 📁 `store.js` Example

```js
// store.js
import { configureStore } from '@reduxjs/toolkit';
import counterReducer from '../features/counter/counterSlice';

export const store = configureStore({
  reducer: {
    counter: counterReducer
  }
});
```

---

## ⚙️ What's Inside `configureStore()`?

```js
configureStore({
  reducer,         // Combined reducer or object of slice reducers
  middleware,      // Built-in middleware like thunk (auto-added)
  devTools: true,  // Enables Redux DevTools
  preloadedState,  // Optional initial state
  enhancers        // Optional custom store enhancers
})
```

---

## 💡 Accessing Store Data in Components

```js
import { useSelector } from 'react-redux';

const value = useSelector((state) => state.counter.value);
```

---

## 🚀 Dispatching Actions from Store

```js
import { useDispatch } from 'react-redux';
import { increment } from '../features/counter/counterSlice';

const dispatch = useDispatch();
dispatch(increment());
```

---

## 🧪 Testing the Store

```js
import { store } from './store';

console.log(store.getState()); // Logs current state
store.subscribe(() => {
  console.log('State changed:', store.getState());
});
```
