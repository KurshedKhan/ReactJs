## 🔍 What is a Selector?

A **selector** is a function that:

* Takes the **Redux store state**
* Returns a **specific piece** of that state

It helps your components **read the state** from the store.

---

## ✅ Syntax with React-Redux

```js
import { useSelector } from 'react-redux';

const data = useSelector((state) => state.sliceName.someProperty);
```

---

## 📦 Example: Counter App

### 1. Slice (counterSlice.js)

```js
const initialState = { value: 0 };

const counterSlice = createSlice({
  name: 'counter',
  initialState,
  reducers: {
    increment: (state) => { state.value += 1 }
  }
});

export const { increment } = counterSlice.actions;
export default counterSlice.reducer;
```

---

### 2. Component: Use Selector

```js
import { useSelector, useDispatch } from 'react-redux';
import { increment } from './counterSlice';

function Counter() {
  const count = useSelector((state) => state.counter.value);  // 👈 Selector
  const dispatch = useDispatch();

  return (
    <div>
      <h2>{count}</h2>
      <button onClick={() => dispatch(increment())}>+</button>
    </div>
  );
}
```

---

## 🎯 Why Use Selectors?

| Benefit               | Description                                        |
| --------------------- | -------------------------------------------------- |
| 🔍 Read specific data | Avoid reading the whole state tree                 |
| 🔁 Auto re-render     | Component only re-renders if selected data changes |
| 🔄 Central logic      | Complex selectors can be reused and tested         |

---

## ⚙️ Optional: Create Custom Selector

```js
// selectors.js
export const selectCount = (state) => state.counter.value;
```

Then in your component:

```js
import { useSelector } from 'react-redux';
import { selectCount } from './selectors';

const count = useSelector(selectCount);
```

## 📚 Advanced Selector (With Reselect)

Install:

```bash
npm install reselect
```

Create memoized selector:

```js
import { createSelector } from 'reselect';

const selectTodos = (state) => state.todos;

export const selectCompletedTodos = createSelector(
  [selectTodos],
  (todos) => todos.filter(todo => todo.done)
);
```

## ✅ Summary

| Term                | Description                                      |
| ------------------- | ------------------------------------------------ |
| `useSelector()`     | React hook to read state                         |
| `selector function` | `(state) => state.slice.value`                   |
| `createSelector()`  | From `reselect`, memoizes output for performance |
