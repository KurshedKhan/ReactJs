## 🧠 What is a Reducer in Redux?

A **reducer** is a **pure function** that:

* Takes the **current state** and an **action**
* Returns the **new state** based on that action

> 🔁 Reducers are the only way to **update Redux state**.

---

### ✅ Reducer Formula:

```js
(state, action) => newState
```

---

## 🔹 Basic Example (Classic Redux)

```js
// counterReducer.js
const initialState = { value: 0 };

function counterReducer(state = initialState, action) {
  switch (action.type) {
    case 'INCREMENT':
      return { value: state.value + 1 };
    case 'DECREMENT':
      return { value: state.value - 1 };
    case 'ADD_AMOUNT':
      return { value: state.value + action.payload };
    default:
      return state;
  }
}

export default counterReducer;
```

> 🎯 Reducer must **not mutate** the state directly in Classic Redux. Always return a new object.

---

## 🔧 With Redux Toolkit (`createSlice`)

Redux Toolkit uses `Immer` behind the scenes, so **you can mutate the state safely** (it’s converted to immutable changes automatically).

```js
import { createSlice } from '@reduxjs/toolkit';

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => { state.value += 1 },
    decrement: (state) => { state.value -= 1 },
    addAmount: (state, action) => {
      state.value += action.payload;
    }
  }
});

export const { increment, decrement, addAmount } = counterSlice.actions;
export default counterSlice.reducer;
```

> ✅ This is cleaner and safer — no `switch` statements!

## 🔀 Combining Reducers (Classic Way)

```js
import { combineReducers } from 'redux';
import counterReducer from './counterReducer';
import userReducer from './userReducer';

const rootReducer = combineReducers({
  counter: counterReducer,
  user: userReducer
});

export default rootReducer;
```

---

## 🧩 In Redux Toolkit (Automatically Combined)

```js
import { configureStore } from '@reduxjs/toolkit';
import counterReducer from './counterSlice';
import userReducer from './userSlice';

const store = configureStore({
  reducer: {
    counter: counterReducer,
    user: userReducer
  }
});
```

---

## ❗ Reducer Rules

| Rule                           | Explanation                                       |
| ------------------------------ | ------------------------------------------------- |
| 🔁 Must be pure                | No API calls, random, or mutations                |
| 📤 Return new state            | Don’t mutate directly (except with `createSlice`) |
| 🧠 Must handle unknown actions | Return state by default (`default` case)          |

---

## 🔄 Flow Summary

```
User → Dispatches Action → Reducer → Store State Updated → UI Renders
```

## 📦 Real Example: Todo Reducer (Toolkit)

```js
const todoSlice = createSlice({
  name: 'todos',
  initialState: [],
  reducers: {
    addTodo: (state, action) => {
      state.push({ id: Date.now(), text: action.payload, done: false });
    },
    toggleTodo: (state, action) => {
      const todo = state.find(t => t.id === action.payload);
      if (todo) todo.done = !todo.done;
    }
  }
});
```
