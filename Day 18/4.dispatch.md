## 🚀 What is `dispatch` in Redux?

### 👉 `dispatch(action)` is a function used to **send an action** to the Redux **store**.

When you dispatch an action:

* It goes to the **reducer**
* The reducer decides **how to update the state**
* The UI gets updated accordingly

---

## 🧠 Syntax:

```js
store.dispatch(actionObject)
```

In a React component using Redux Toolkit and React-Redux:

```js
const dispatch = useDispatch();        // Hook
dispatch(increment());                 // Dispatching an action
```

---

## 🔧 Example Flow (with Toolkit)

### 1. Create a Slice

```js
// counterSlice.js
import { createSlice } from '@reduxjs/toolkit';

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => { state.value += 1 },
    decrement: (state) => { state.value -= 1 },
    addAmount: (state, action) => { state.value += action.payload }
  }
});

export const { increment, decrement, addAmount } = counterSlice.actions;
export default counterSlice.reducer;
```

---

### 2. Dispatch in Component

```js
// Counter.js
import React from 'react';
import { useDispatch, useSelector } from 'react-redux';
import { increment, decrement, addAmount } from './counterSlice';

function Counter() {
  const count = useSelector(state => state.counter.value);
  const dispatch = useDispatch();

  return (
    <div>
      <h2>{count}</h2>
      <button onClick={() => dispatch(increment())}>+</button>
      <button onClick={() => dispatch(decrement())}>-</button>
      <button onClick={() => dispatch(addAmount(5))}>Add 5</button>
    </div>
  );
}
```

## ✅ Summary Table

| Term            | Description                                  |
| --------------- | -------------------------------------------- |
| `dispatch()`    | Sends an action to the store                 |
| `useDispatch()` | Hook to access `dispatch` in React           |
| `action`        | Object describing what happened              |
| `reducer`       | Logic that updates the state based on action |
