## 🍰 What is a Slice in Redux Toolkit?

A **slice**:

* Is a collection of **state**, **reducers**, and **actions** grouped together
* Represents a **slice of your global Redux state**
* Automatically creates action creators and reducer logic for you

> ✅ With `createSlice()`, Redux Toolkit makes Redux **simple, readable, and powerful**.

---

## 🛠 `createSlice()` Syntax

```js
import { createSlice } from '@reduxjs/toolkit';

const sliceName = createSlice({
  name: 'sliceName',
  initialState: {},
  reducers: {
    // Your reducer functions go here
  }
});
```

---

## 📦 Example: `counterSlice.js`

```js
// features/counter/counterSlice.js
import { createSlice } from '@reduxjs/toolkit';

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => {
      state.value += 1;
    },
    decrement: (state) => {
      state.value -= 1;
    },
    addAmount: (state, action) => {
      state.value += action.payload;
    }
  }
});

// auto-generated action creators
export const { increment, decrement, addAmount } = counterSlice.actions;

// auto-generated reducer
export default counterSlice.reducer;
```

## 📥 Using a Slice in the App

### 1. Add to Store

```js
// app/store.js
import { configureStore } from '@reduxjs/toolkit';
import counterReducer from '../features/counter/counterSlice';

export const store = configureStore({
  reducer: {
    counter: counterReducer
  }
});
```

---

### 2. Access in Component

```js
import { useSelector, useDispatch } from 'react-redux';
import { increment, decrement } from '../features/counter/counterSlice';

function Counter() {
  const count = useSelector((state) => state.counter.value);
  const dispatch = useDispatch();

  return (
    <div>
      <h2>{count}</h2>
      <button onClick={() => dispatch(increment())}>+</button>
      <button onClick={() => dispatch(decrement())}>−</button>
    </div>
  );
}
```

## ✅ Advantages of Slice

| Feature           | Benefit                            |
| ----------------- | ---------------------------------- |
| 📦 Bundles logic  | Reducers + Actions together        |
| 🛠 Auto generates | Action creators and action types   |
| 💡 Clean code     | Reduces boilerplate                |
| ⚡ Fast updates    | Uses Immer for safe state mutation |

---

## 🧠 Summary

| Part           | Example                                  |
| -------------- | ---------------------------------------- |
| `name`         | `'counter'`                              |
| `initialState` | `{ value: 0 }`                           |
| `reducers`     | `increment`, `decrement`, etc.           |
| `actions`      | Auto-exported via `counterSlice.actions` |
| `reducer`      | Auto-exported via `counterSlice.reducer` |
