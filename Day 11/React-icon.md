Sure! Here's a simple guide to **React Icons** :

### 🛠 How to Install?

Use npm:

```bash
npm install react-icons --save
```

---

### 🧩 How to Use?

```jsx
import { FaBeer } from "react-icons/fa";

function MyComponent() {
  return <h3>Let’s go for a <FaBeer />?</h3>;
}
```

---

### 🔎 Popular Icon Packs:

| Icon Pack       | Prefix | Description                  |
| --------------- | ------ | ---------------------------- |
| Font Awesome    | `fa`   | Social, web, UI icons        |
| Material Design | `md`   | Google Material icons        |
| Bootstrap Icons | `bs`   | Bootstrap style icons        |
| Remix Icons     | `ri`   | Minimal and modern icon set  |
| Feather Icons   | `fi`   | Lightweight and simple icons |
| BoxIcons        | `bi`   | Box-style icons              |

---

Visit:

### 🧪 Example:

```jsx
import { MdEmail } from "react-icons/md";
import { FaFacebook, FaInstagram } from "react-icons/fa";

function Footer() {
  return (
    <div>
      <MdEmail /> contact@example.com  
      <FaFacebook />  
      <FaInstagram />
    </div>
  );
}
```
